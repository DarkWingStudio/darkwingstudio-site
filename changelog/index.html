Changelog

A clear, chronological record of releases, architectural decisions, design updates, and technical milestones behind DarkWing Studio.

Release History

v3.2.0 Latest Release
November 9, 2026

Arcade T-Rex Runner & Dedicated Hub: Replaced the experimental glider prototype with a complete, delta-time powered T-Rex Runner game featuring a DarkWing winged silhouette runner, procedural obstacle generation, day/night cycle, accessible HTML overlay HUD, and a dedicated Arcade Hub listing page.

  • Added Dedicated Arcade Hub: Launched /arcade/ hub featuring game cards styled with existing studio asset-card design patterns, live canvas previews, and offline status indicators.
  • Added T-Rex Runner Game: Built standalone game at /arcade/t-rex-runner/ with frame-rate independent delta-time physics, canvas-rendered silhouette art, procedural cactus-style spires, and Web Audio sound effects.
  • Features Day/Night Cycle & Token Integration: Implemented smooth background and ink crossfading at 300-point score intervals reading CSS design tokens directly from computed styles.
  • Accessibility HTML HUD & Motion Controls: Separated score and control HUD into semantic HTML overlay with screen-reader live announcements (aria-live="polite") and respect for prefers-reduced-motion.
  • PWA Scoped Service Worker: Registered dedicated offline cache for /arcade/t-rex-runner/ ensuring zero-network offline playability and graceful retirement of legacy cache keys.
v3.1.0
November 9, 2026

Studio PRD Execution & Feature Expansion: Shipped complete PRD audit remediation (Phase 0–4) — eliminated all CSP-violating inline styles, deleted 70 dead utility classes, split stylesheets into modular CSS tokens, built automated Node generator pipeline (scripts/generate.js), and restored the structured Minecraft Mob Database from JSON models.

  • Security Zero CSP Violations: Removed all legacy inline styles across all pages; verified strict style-src 'self' and script-src 'self' compliance with 0 console warnings.
  • Architecture Modular Stylesheet Suite: Split styles.css into 4 dedicated modules under styles/ (tokens, layout, components, pages) compiled at build time with 0 syntax errors and all 70 dead u-inline-* classes purged.
  • Added Node Static Generator: Introduced zero-dependency build script (npm run generate) that reads JSON datasets, generates static mob encyclopedias, and keeps sitemap.xml updated.
  • Added Minecraft Mob Database: Shipped 8 verified entity pages under /minecraft/mobs/{slug}/ with combat stats, hostility tags, variants, and drop tables powered by data/mobs.json.
v3.0.0
November 9, 2026

Studio Streamlining & Section Redesign Prep: Detached the Minecraft guide section to prepare for a planned standalone rebuild, keeping this link-in-bio platform fast and focused while allowing the database experience to be developed properly.

  • Archived Detached the Minecraft guide pages from this repository ahead of a planned standalone rebuild, giving the database room to be re-architected and worked on properly.
  • Improved Streamlined global topbar navigation, sidebar navigation, and footer columns across all pages to focus purely on About, Projects, and Digital Art.
  • Improved Overhauled the custom 404 recovery portal (`/404.html`) with a balanced 2x2 grid, instant client-side keyword search, and zero broken links.
  • Added Clean vector asset suite: built hand-crafted pixel-art SVGs (`viewBox="0 0 16 16"`, `crispEdges`, `fill="currentColor"`) to replace heavy raster PNG icons.
  • Improved Repository hygiene: updated `.gitignore` rules to keep heavy binary assets isolated, keeping git history lightweight and Netlify builds instant.
  • Security Hardened HTTP headers in `netlify.toml` with strict CSP, HSTS preload flags, iframe clickjacking guards, and MIME sniffing protection.
v2.5.0
October 26, 2026

Asset Directory Modularization & Grid Optimization: Restructured static media into categorized folders and introduced responsive high-density card layouts.

  • Improved Reorganized static assets into clean categorical subdirectories under `/assets/` for maintainable file management.
  • Improved Built responsive multi-column CSS card grids (`.asset-grid`) that flex naturally from 320px mobile viewports to desktop widths.
  • Added Structured data records and JSON schemas for lightweight client-side parsing without server runtimes.
v2.3.0
October 25, 2026

Technical SEO & Machine Readability: Implemented comprehensive Schema.org metadata, crawler directives, and machine-readable context files.

  • Added Schema.org `@graph` JSON-LD data linking Organization, WebSite, CollectionPage, and BreadcrumbList structured entities.
  • Added Machine-readable `llms.txt` in workspace root, offering concise public context for automated discovery and AI indexation.
  • Improved High-resolution 1200x630 OpenGraph and Twitter card social preview cards across all studio sections.
  • Fixed XML sitemap priority tags, canonical URLs, and explicit crawling permissions in `robots.txt`.
v2.2.0
October 25, 2026

Responsive Hardening & Vector System: Replaced OS-dependent emoji characters with custom SVG vectors and resolved mobile viewport constraints.

  • Fixed Mobile footer cut-off bug on narrow screens by replacing rigid absolute units with fluid vertical flexbox flow.
  • Improved Enforced a strict zero-emoji design standard across the site, switching entirely to custom inline SVGs for reliable cross-platform rendering.
  • Improved Centered content alignment and unified typographic rhythm across mobile, tablet, and desktop viewports.
v2.1.0
October 25, 2026

Privacy Architecture & Licensing Framework: Formalized transparent visitor protections and creative asset licensing terms.

  • Added Dedicated Privacy Policy (`/privacy/`) verifying the site's tracker-free, cookie-less architecture and static edge delivery.
  • Added Official Terms of Use (`/terms/`) documenting personal wallpaper download licenses and MIT open-source code usage.
v1.0.0
September 15, 2026

Studio Launch: Initial public release of DarkWing Studio as a personal creative portfolio and curated link hub.

  • Added Minimalist dual-panel layout with off-white warm paper palette (`#f2f0e9`) and dark contrast accents.
  • Added Integrated social channels for GitHub, YouTube, Instagram, X, Pinterest, Reddit, and DeviantArt.
  • Added Digital art wallpaper and avatar download library at `/art/assets/`.
